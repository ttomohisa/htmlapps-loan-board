# Loan Board / 貸出・返却ボード

イベント、学校、撮影現場などの短期貸出で、誰が何を持っていて、何がまだ返ってきていないかを1台の端末で確認するブラウザーアプリです。

現在は **v0.6.0（備品管理 / 連番登録）** です。

## v0.6.0でできること
- 備品 / 貸出先の登録・編集
- **連番の備品をまとめて登録**
- 連番登録前のプレビュー
- 管理コードprefix付き連番
- 生成する管理コードの重複チェック
- 備品検索
- 有効 / アーカイブ済み / すべて の表示切替
- 使わない備品のアーカイブ / 復帰
- 貸出中備品のアーカイブ禁止
- 複数備品をまとめて貸出
- 二重貸出防止
- 全返却 / 部分返却
- 未返却ボード
- 直前の貸出 / 返却のUndo
- Checkout / Return / Undo履歴
- 履歴検索・絞り込み・並び順
- 日本語 / 英語
- PC / タブレット / スマートフォン
- 完全ローカル処理
- 実行時外部通信なし
- 単一HTML

## 連番をまとめて登録

たとえば無線機20台を登録する場合、

```text
備品名の共通部分: 無線機
開始番号: 1
登録数: 20
桁数: 2
管理コードの共通部分: RADIO-
```

とすると、

```text
無線機 01 / RADIO-01
無線機 02 / RADIO-02
...
無線機 20 / RADIO-20
```

をまとめて作れます。

登録前にプレビューを表示します。登録数は最大500件で、生成番号は999999を超えない範囲に制限しています。

管理コードを生成する場合、既存の備品（アーカイブ済みを含む）と重複するコードがあると一括登録できません。

## アーカイブ

使わなくなった備品は削除せず、**アーカイブ**します。

アーカイブすると貸出候補から外れますが、過去の貸出・返却履歴は残ります。必要になったら「アーカイブ済み」から復帰できます。

**貸出中の備品はアーカイブできません。** 先に返却してください。

## Undoとの関係

返却直後の備品をアーカイブすると、その返却は現在状態と整合しなくなるためUndo対象から外れます。アーカイブ済み備品をUndoによって貸出中へ戻すことはありません。

## 現在の制限
v0.6.0では備品・貸出先・貸出返却状態・履歴・アーカイブ状態はメモリ上だけに保持します。**ページを再読み込みするとすべて消えます。**

自動保存とJSONバックアップ / 復元はv0.7.0で追加予定です。

## プライバシー
入力内容、貸出返却状態、操作履歴を外部サーバーへ送信しません。ランタイムCDN、API、分析、テレメトリは使用しません。

## 単一HTML / オフライン
`dist/index.html`, `dist/index.self-extract.html`, `loan-board.html` を生成します。実行時の外部ネットワーク依存はありません。
