# Loan Board / 貸出・返却ボード

イベント、学校、撮影現場などで使う備品について、誰に何を貸しているかと未返却を確認するためのブラウザーアプリです。

現在は **v0.1.0（基礎データ）** の開発段階です。備品・貸出先の登録と編集、Boardの基本UIまで実装しています。貸出・返却処理はv0.2.0以降で追加します。

## v0.1.0でできること

- Board名の編集
- 備品の追加・編集
- 備品カテゴリ・管理コード・メモ
- 貸出先の追加・編集
- 件数サマリー
- 日本語 / 英語切替
- PC / タブレット / スマートフォン対応
- 完全ローカル処理
- 実行時外部通信なし
- 単一HTMLビルド

## 現在の制限

v0.1.0では備品・貸出先などの業務データはメモリ上だけに保持します。**ページを再読み込みすると登録内容は消えます。**

自動保存とバックアップ・復元はv0.7.0で追加予定です。

また、以下はまだ実装していません。

- 貸出
- 返却 / 部分返却
- 未返却ボード
- Undo / 履歴
- 連番登録
- CSV出力

## プライバシー

入力した備品情報や貸出先情報は、このアプリから外部サーバーへ送信しません。ランタイムCDN、API、分析、テレメトリは使用しません。

v0.1.0では業務データを永続保存しません。言語設定のみブラウザーへ保存する場合があります。

## 単一HTML / オフライン

ビルドすると以下を生成します。

- \`dist/index.html\`
- \`dist/index.self-extract.html\`
- \`loan-board.html\`

必要なコードはHTMLへ内包され、実行時の外部ネットワーク依存はありません。
