# Loan Board / 貸出・返却ボード

イベント、学校、撮影現場などの短期貸出で、誰が何を持っていて、何がまだ返ってきていないかを1台の端末で確認するブラウザーアプリです。

現在は **v0.7.0（保存 / JSONバックアップ）** です。

## v0.7.0でできること
- 備品 / 貸出先の登録・編集
- 連番の備品をまとめて登録
- 備品のアーカイブ / 復帰
- 複数備品をまとめて貸出
- 全返却 / 部分返却
- 未返却ボード
- 直前の貸出 / 返却のUndo
- Checkout / Return / Undo履歴
- **このブラウザーへの自動保存**
- **再読み込み後の自動復元**
- **保存状態と最終保存時刻の表示**
- **JSONバックアップ**
- **JSONバックアップから全データ復元**
- 日本語 / 英語
- PC / タブレット / スマートフォン
- 完全ローカル処理
- 実行時外部通信なし
- 単一HTML

## 自動保存

備品、貸出先、貸出状態、返却状態、履歴、アーカイブ状態、ボード名をブラウザー内へ自動保存します。

変更後に短いdebounceを挟んで保存し、画面の「データ管理」で保存状態と最終保存時刻を確認できます。

再読み込み時は、保存データの形式と参照関係を確認してから復元します。

保存データが壊れている場合は**空データで自動上書きしません**。JSONバックアップから復元するか、明示的に新しいボードへリセットするまで自動保存を止めます。

## JSONバックアップ

「JSONバックアップを保存」では、次をまとめて1ファイルへ保存します。

- Board
- Items
- Borrowers
- Checkout / Return / Undo Events
- アーカイブ状態
- 現在の貸出状態

CSVとは違い、JSONバックアップは**Loan Board全体を復元するための形式**です。

復元時にはファイル形式・schema・ID参照・貸出状態を検証し、問題がなければ現在のボードを置き換える確認を表示します。

## 保存についての注意

自動保存はクラウド同期ではありません。

- ブラウザーのサイトデータを削除すると消えます。
- プライベートブラウズでは永続化されない場合があります。
- 単一HTMLを `file://` で開く場合、ブラウザーやファイルの開き方・保存場所によって保存領域の扱いが異なる場合があります。
- 別端末・別ブラウザーへ自動同期しません。

重要なイベントや長期運用では、**JSONバックアップを併用してください。**

## プライバシー
自動保存もJSONバックアップも端末内で処理します。入力内容やファイルを外部サーバーへ送信しません。ランタイムCDN、API、分析、テレメトリも使用しません。

## 単一HTML / オフライン
`dist/index.html`, `dist/index.self-extract.html`, `loan-board.html` を生成します。実行時の外部ネットワーク依存はありません。
