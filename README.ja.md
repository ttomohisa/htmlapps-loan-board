# Loan Board / 貸出・返却ボード

イベント、学校、撮影現場などで使う備品について、誰に何を貸しているかと未返却を確認するためのブラウザーアプリです。

現在は **v0.2.0（Checkout / 貸出）** です。備品と貸出先を登録し、貸出先を選んで複数の備品をまとめて貸し出せます。

## v0.2.0でできること
- Board名の編集
- 備品 / 貸出先の追加・編集
- 貸出先の検索とその場での新規追加
- 利用可能備品を名前・カテゴリ・コードで検索
- 複数備品をまとめて貸出
- 貸出中備品の二重貸出防止
- 備品一覧で貸出先・貸出日時を確認
- 貸出先ごとの現在貸出中件数
- 日本語 / 英語
- PC / タブレット / スマートフォン
- 完全ローカル処理、実行時外部通信なし
- 単一HTML

## 現在の制限
v0.2.0では備品・貸出先・貸出状態はメモリ上だけに保持します。**ページを再読み込みするとすべて消えます。**

返却 / 部分返却はv0.3.0、自動保存とバックアップ・復元はv0.7.0で追加予定です。

## 貸出方法
1. 備品を登録します。
2. 「貸し出す」で貸出先を検索・選択します。新しい貸出先はその場で追加できます。
3. 利用可能な備品を1件以上選択します。
4. 貸出ボタンを押します。
5. 貸出済みの備品は「貸出中」となり、別の貸出には選べません。

## プライバシー
備品情報、貸出先情報、貸出状態は外部サーバーへ送信しません。ランタイムCDN、API、分析、テレメトリは使用しません。

## 単一HTML / オフライン
`dist/index.html`, `dist/index.self-extract.html`, `loan-board.html` を生成します。実行時の外部ネットワーク依存はありません。
